# Event Type Taxonomy Expansion & Reorganization

**Version:** 2.0 Proposal  
**Date:** January 1, 2026  
**Status:** Pending Implementation

---

## Executive Summary

This document consolidates three separate expansion proposals into a single, comprehensive event type taxonomy. The goal is to transform generic categories into specific, discoverable event types while maintaining all existing data and improving user experience.

**Key Changes:**
- Expand from **49 event types** to **~120 event types**
- Reorganize into **7 main categories** with logical subcategories
- Deprecate 7 overly-generic types (keep as fallbacks)
- Improve discoverability and reduce mis-tagging

---

## Current State Analysis

### Strong Categories (Keep Structure)
- **Family & Kids** (8 types) - Activity-specific, works well
- **Arts & Culture** (9 types) - Covers main areas adequately
- **Community & Social** (18 types) - Recently expanded, comprehensive

### Weak Categories (Needs Expansion)
- **Recreation & Sports** (3 types) - Too generic, everything lumped together
- **Health & Wellness** (4 types) - Only covers studio fitness, missing holistic/mental health
- **Markets & Festivals** (3 types) - Critical for discovery but too broad

### Problematic Category
- **Seasonal** (15 types) - Mixes holidays, seasons, and event types causing confusion

## Types to Deprecate (Not Delete)

These 7 types are too generic and cause confusion. Mark as **legacy/fallback** options:

1. **Sports & Recreation** → Replaced by 20 specific sports types
2. **Outdoor Adventure** → Replaced by specific outdoor activities
3. **Fitness** → Replaced by specific fitness types
4. **Wellness Workshops** → Replaced by specific wellness types
5. **Craft Shows & Markets** → Replaced by specific market types
6. **Festivals & Fairs** → Replaced by specific festival types
7. **Food & Drink** → Replaced by Food Festivals, Tasting Events

**Implementation:** Keep in database, but hide from primary selection UI. Show only if user searches or if existing events use them.

## UI/UX Recommendations

### Event Submission Form

**Option A: Grouped Dropdown**
```
Select Event Type(s):
▼ Family & Kids
  - Toddler & Preschool Activities
  - Kids Crafts
  - Birthday Parties
  ...
▼ Arts & Culture
  - Live Music
  - Theatre & Performances
  - Comedy Shows
  ...
▼ Community & Social
  - Trivia
  - Book Clubs
  - Networking Events
  ...
```

**Option B: Multi-Step Selection**
```
Step 1: Choose Category
[Family & Kids] [Arts & Culture] [Community & Social] ...

Step 2: Choose Specific Type(s)
[Toddler Activities] [Kids Crafts] [Birthday Parties] ...
```

**Option C: Searchable Tags (Recommended)**
- Show all types as searchable, filterable chips
- Group by category with collapsible sections
- Allow multiple selection
- Show popular types first within each category

### Browse/Filter UI

- Show category filters first
- Expand to show specific types
- Display count of events per type
- Allow multi-select filtering

## Implementation Strategy

### Phase 1: Database Setup
1. Add new event types to database (assign IDs 200001-200120)
2. Mark deprecated types with `isDeprecated` flag
3. Keep all existing type assignments intact

### Phase 2: UI Updates
1. Update event submission form with new grouped structure
2. Update browse/filter interface
3. Update admin event type management

### Phase 3: Migration & Cleanup
1. Create admin tool to reassign events from deprecated types to specific types
2. Update documentation (REFERENCE_IDS.md, CSV_IMPORT_GUIDE.md)
3. Notify organizers of new options

### Phase 4: Monitoring
1. Track which new types are most used
2. Identify gaps or unused types
3. Iterate based on real usage
